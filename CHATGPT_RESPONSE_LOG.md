# ChatGPT response record — Andor's Trail / AnkiDroid

This GitHub-hosted file records statements made by the assistant in the project's ChatGPT conversations. The purpose is to have a linkable, externally hosted record when the assistant loses context or contradicts a previous claim.

## Important limitations

- **Recording is manual, not automatic.** ChatGPT does not write every reply to this file by itself. An assistant instruction is not a reliable enforcement mechanism; an independent recorder would be needed for comprehensive automatic logging.
- **No claim of completeness.** This file begins on 2026-10-18. Earlier conversation history has not been backfilled. Entries must never be passed off as the entire conversation if only excerpts were captured.
- **GitHub's commit history supplies dated revisions**, but GitHub is not an immutable witness: someone with write/administration permissions can edit the file or rewrite repository history. Keep a copy of important commit SHA links elsewhere when evidence matters.
- All future entries should be **verbatim**, clearly separated from summaries or commentary, include a date, and indicate if they are partial or complete. New entries should be appended rather than silently replacing old statements.
- Logging should not contain passwords, access tokens, Anki card answers, private personal data, or sensitive user attachments.
